General Guidelines (Delete this page when making the report submission)

 

 

ü  Project Report to be minimum 12 pages. Reports less than 12 pages will be rejected.

 

ü  Paper Size: A4; Left = Right = Top = Bottom Margins = 0.7”

 

ü  Page Numbering Position: Bottom with right justified and continuous numbering from the Introduction Chapter

 

ü  Normal Paragraph: Use Times New Roman Font, font size 12 with Normal Style, justified alignment and 1.15 line spacing

 

ü  Heading: Times New Roman Font, Bold, Font Size 14;

 

ü  Sub-heading be numbered as in 1.1, 1.2, 1.3 etc.; Sub-Heading: Times New Roman Font, Italics, Font Size 12; Sub-paragraph Matter: Times New Roman Font, Normal, Font Size 12.

ü  Figure captions below Figure with chapter wise numbering

 

ü  Tables captions above Table with chapter wise numbering

 

ü  All references must be listed in the order in which they appear in the report (follow IEEE format for referencing)

 

ü  Arrangement of contents
